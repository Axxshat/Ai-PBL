# Smart Academic Timetable Management System
AI (CCSAI0301) PBL - B.Tech CSE, NIET Greater Noida.

Static website, no build step.
- Netlify Drop: https://app.netlify.com/drop -> drag this folder (or the zip) in.
- Local: `python -m http.server 8000` then open http://localhost:8000
- Files: index.html, style.css, app.js (UI), solver.js (CSP + GA engine), reference/ (credited reference repo).
